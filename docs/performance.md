# Performance evidence

Each gameplay record retains its own linked native UI, engine and drive-model
properties. UI horsepower/mass and physical mass are distinct specifications.
Unknown values remain null; no related model supplies a guessed replacement.

Calculated gearing ceilings select the highest positive `maxSpeed` from forward
gears. Index zero is the native reverse gear. Raw gear records and per-gear
conversions remain published with the result.

```text
world km/h = gear maxSpeed × 3.6
world mph = gear maxSpeed × 3600 / 1609.344
HUD mph = gear maxSpeed × speed_to_multiplier(gear maxSpeed)
HUD km/h = HUD mph × 1.60934
```

The main HUD speed curve comes from the native vehicle UI curveset. Legacy
Bezier evaluation solves its time coordinate before evaluating its value;
control handles are not independent keys. Curve resources and decoded-document
fingerprints are published. Missing/unsupported HUD curves produce unavailable
HUD values and diagnostics while preserving world-space gearing ceilings.

Torque curves retain their source and values at normalized RPM 1. These are not
a full engine, drag or traction simulation. Calculated ceilings do not claim
achieved sustained speed, acceleration or braking distance. Terrain, behavior
and runtime changes can affect actual performance.

Authored, calculated and measured evidence are separate. No runtime measurements
are generated by this catalogue; measurement collections initially remain empty.

Native gear layout is documented in the local modding reference:
`modding_docs/modding-guides/vehicles/changing-handling-and-speed-for-modded-vehicles.md`
in the Ghostline reference repository.
