# Vehicles

Use native Rust generation. Native decoding belongs in `ghostline-red`; reusable
GPU rendering belongs in `renderer`. Vehicles owns catalogue discovery, performance
calculations, comparison, recipes and publication. Keep records and appearances
separate. No Python migration or runtime spawning. Generated output belongs in
`dist/`; intermediates in `work/`. Validate native builds, representative renders,
source provenance, hosted subpaths and offline `file://` browsing.
